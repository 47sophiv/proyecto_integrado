# Clínica Dental Diente Feliz

## Iniciar la aplicación

Requiere Node.js 18 o posterior. Ejecuta `npm start` y abre <http://localhost:3000>. No abras `index.html` directamente como archivo.

El mockup conserva las firmas y fichas en el almacenamiento local del navegador: no es un sistema de producción para almacenar datos clínicos.

## Pruebas

Ejecuta `npm test` para verificar el servidor y los archivos estáticos.
